                        La base de données

                        Le cœur du jeu, table par table, en lecture seule : rien ne peut être modifié d’ici. Les mots de passe et les clés secrètes ne sont jamais affichés.

                        Tables

                        Choisis une table.

                        Fonctions du jeu

                        Toutes les règles du jeu écrites dans la base (frapper un bloc, acheter, ouvrir un coffre…). Touche une fonction pour lire son code. Les fonctions « internes » ne peuvent pas être appelées depuis le jeu.

                        Le journal

                        Les sessions de jeu terminées (une coupure de moins d’une minute ne compte pas), les plus récentes d’abord.

                        🎛️ Contrôle du jeu

                        Tout ce qui se règle d’habitude dans 👑, rangé par thème. Les changements sont appliqués tout de suite, et les joueurs connectés sont prévenus quand il le faut. Les actions sensibles demandent une confirmation.
